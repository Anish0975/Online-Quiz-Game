# Online Quiz Game

## Project Description

Online Quiz Game is a command-line based Python application.
It allows users to answer multiple-choice questions and receive
their score and percentage at the end of the quiz.

## Features

- 10 multiple-choice questions
- Simple command-line interface
- Instant answer feedback
- Score calculation
- Percentage calculation
- Instructions menu
- Input validation
- Play again option

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Download or clone the project.
2. Open the project folder in a terminal.
3. Run the following command:

```bash
python quiz.py
